# My Portfolio

[Live Demo](https://agnisweb.dev/)

This is my personal portfolio website, built with modern web technologies to create an interactive, high-performance, and visually engaging user experience.

## 🚀 Tech Stack

The project leverages the latest frontend tools and libraries:

- **Framework:** [Next.js](https://nextjs.org/) (React 19)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) and [Lottie React](https://github.com/gamier/lottie-react)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)


## ✨ Features

- **Fluid Animations:** Smooth transitions and entry effects using Framer Motion.
- **Fully Responsive:** Optimized for all screen sizes, from mobile devices to large desktop monitors.
- **Dark/Light Mode:** Seamless theme switching to match user preference.
- **Optimized Performance:** Built with Next.js 15+ features for fast loading and SEO optimization.

## 🛠️ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/IWill29/My-portfolio.git
   cd My-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📂 Project Structure

- `app/` - Core Next.js application logic and routing.
- `components/` - Reusable UI components.
- `data/` - Static data (projects, experience, etc.).
- `lib/` - Utility functions and configurations.
- `public/` - Static assets (images, Lottie files).
